Datenschutzerklärung rclone-familie

rclone-familie ist ein privates Werkzeug, das nur vom Eigentümer dieses GitHub-Kontos für sein eigenes Google-Konto genutzt wird.

  • Die App greift über die Google Drive API nur auf Dateien im eigenen Google Drive zu: lesend für eine lokale Kopie und schreibend nur auf Dateien, die sie selbst angelegt hat (verschlüsselte Sicherungen).
  • Die Daten werden ausschliesslich auf einem privaten Server im eigenen Haushalt verarbeitet.
  • Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt.
  • Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.
